# Daily Agent release 13 驗證｜2026-10-07

本頁記錄 `0.2.2-release-20261007-13` 的程式碼、Windows 安裝包及驗證界線。Android 沿用已發布的 Preview 10；舊驗收保留在 [2026-10-03 歷史](docs/驗證歷史-0.2.2-20261003.md)，不拿舊版測試數量代表目前結果。

## 本輪範圍

- 聊天先由 Daily 自己的 Qwen 理解，再依需求搜尋或回答；生圖、文件與明確助理命令使用各自路徑。
- 搜尋改為 Exa Auto → Tavily Basic → Firecrawl Search；自己的金鑰、用量、快取、冷卻與鎖保存於自己的資料目錄。
- 安裝勾選、下載、更新、模組設定、環境範本與目前教學不再使用舊本機搜尋核心。
- 發布前檢查程式、範本、安裝指令與文件；退役整合出現時拒絕打包。
- 保留拒絕舊插件的安裝防護及回歸負例。歷史文件明確標為舊版，不是操作指南。

## 驗證方式與限制

逐項執行 `node --test --test-concurrency=1 tests/*.test.js`，253 項通過，測試模型取消、記憶、助理、文件、模組、搜尋 API 輪替、認證、Drive 模擬回呼、手機 API、OTA、安裝校驗、下載續傳與卸載資料保留。本機 HTTP／HTTPS 回呼測試曾間歇出現 ECONNRESET（含逐項與併行執行），尚未證實原因；成功重跑不代表這項環境問題已修復。

安裝版使用隔離資料測試：所有可選模組關閉、缺少分詞套件、模型離線時仍可開設定與記憶；另一項隔離測試使用模擬模型與搜尋 API，驗證金鑰加密、輪替、重啟與設定畫面。測試實例結束後關閉，不使用真實帳戶金鑰或使用者宮殿。

Windows 發行包另驗證 EXE 解出檔案的 manifest 校驗、全新安裝、重跑安裝、升級、回復及拒絕被修改的包。2026-10-05 曾以同一程式功能在本機重新安裝，核驗語音與生圖資源並實測 Qwen 回覆；本次發布沒有重新跑全部硬體情境。

搜尋正式帳戶、Google OAuth／Drive、Android 實體手機觸控／背景／耗電、各顯卡與音訊設備仍需要各自實機驗收。Windows 安裝器尚未正式簽章。模擬測試通過不代表這些外部條件已驗收。

## APK 與公開版本

APK 獨立在 GitHub 發布，電腦安裝器提供 QR 下載，沒有把 APK 或模型打進 Windows 包。Preview 10 使用固定簽章；Preview 9 以前需要重裝與重新配對。每個發布的 SHA-256、大小與版本以該發布的 metadata 為準。

本次發布不修改 Cloudflare 或其他 App，不會替使用者安裝或移除系統上的其他程式。個人資料、配對、金鑰、模型權重與私鑰均不放入 Git 或發布資產。
