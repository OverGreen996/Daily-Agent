# 對話指令與操作

以下為目前程式的明確命令。一般聊天、搜尋、讀圖可自然提問；設定命令若沒反應，先照表輸入。PC 原生介面命令與 Android 命令不同。LLM 自然語言工具呼叫仍可能失敗，不代表每種表述都是固定命令。

## 電腦：外觀與泡泡

| 功能 | 指令或操作 |
|---|---|
| 活動區域 | 框選活動區域／設定活動區域；也可右鍵框選 |
| 移動 | 自由走動／開始走動；停止走動／留在原地 |
| 自主動作 | 開啟自主動作／關閉自主動作 |
| 手動動作 | 揮手／打招呼、跳一下／跳一跳、左右張望／四處看看 |
| 滑鼠跟隨 | 右鍵設定開關；16 方向不用於自動隨機動作 |
| 更換皮膚 | 右鍵設定中的外觀匯入，選透明 PNG／WebP 或 v2 ZIP |
| 傳送皮膚 | 傳送外觀到手機／把寵物傳到手機 |
| 歷史 | 右鍵設定開啟／關閉歷史模式 |
| 關閉 | 右鍵可僅關閉桌寵，或關閉桌寵並停止背景服務 |
| 圖片另存 | 儲存剛才的圖片／保存剛才的圖片；點縮圖放大 |

## 電腦：語音

其他泡泡／外觀命令：更換寵物形象、載入寵物形象、換回露米、使用內建露米；顯示歷史對話／開啟歷史對話／查看對話紀錄；隱藏歷史對話／關閉歷史對話；展開對話／查看詳細；縮小對話／回到泡泡；收起對話／隱藏對話／收起泡泡；保持置頂／取消置頂；停止動畫／恢復動畫；看著滑鼠／停止跟隨滑鼠；變大一點／變小一點；泡泡半透明／泡泡不透明；移除圖片／取消圖片／移除文件／取消文件／取消附件；關閉桌寵／退出桌寵。

- 開啟麥克風／開始聆聽／開啟語音。
- 關閉麥克風／停止聆聽／關閉語音。
- 語音回覆開關與裝置：右鍵設定；麥克風與播放裝置分開選。
- 測試麥克風／測試收音；測試語音播放／測試喇叭。
- 停止朗讀／停止說話／安靜。
- 使用Kokoro語音；使用Windows語音。
- 使用zf_001聲線（其他支援的聲線由設定選；不保證任意編號存在）。
- 語速快一點／說快一點；語速慢一點／說慢一點。
- 語速正常／恢復正常語速；語速1.2倍。
- 開啟通知提醒／關閉通知提醒（需 Windows 授權／套件身分）。

## Agent 狀態與 Idle

- 查看狀態／顯示目前狀態。
- 查看搜尋狀態。
- 進入待機／休息一下／讓露米休息。
- 開啟天氣提醒／關閉天氣提醒；開啟天氣通知／關閉天氣通知。
- 天氣更新間隔改成10分鐘（支援10、15、20）。
- 開啟環境觀察／關閉環境觀察。
- 開啟陌生軟體查詢／關閉陌生軟體查詢。
- 開啟畫面觀察／關閉畫面觀察（低頻截圖與 OCR）。
- 開啟定時畫面觀察／關閉定時畫面觀察（同一設定）。
- 開啟高階畫面觀察／關閉高階畫面觀察（按需使用完整模型；啟用時亦開低頻畫面觀察）。
- 開啟記憶閒聊／關閉記憶閒聊。
- 看看我在做什麼／看一下畫面／看看目前畫面（手動低解析度觀察）。

一般問「今天天氣？」即可查詢；主動提醒需要另行開啟。5 分鐘未互動進 Idle，搭話還要經過事件分數、冷卻及去重，不是每5分鐘一定說一句。

## 記憶宮殿

- 查看記憶宮殿：泡泡列出摘要；PC「打開記憶宮殿／開啟記憶書架」打開管理頁。
- 記住：我喜歡簡短回答。
- 記住偏好：內容；記住規則：內容；記住決定：內容。
- 查看永久記憶；查看永久記憶第2頁。
- 搜尋永久記憶：關鍵字。
- 修改記憶 編號：新內容。
- 刪除記憶 編號（僅移除 pin，原始聊天仍保存）。
- 查看記憶衝突；使用新記憶 編號；保留舊記憶 編號。

編號取自查詢結果。生圖指令／prompt 不寫入記憶宮殿；圖片檔本身不因此刪除。

## 網頁、文件、基本工具

- 幫我搜尋最新 AI 新聞，附上來源。
- 閱讀 https://example.com 並摘要。

- 拖入圖片／貼上圖片，再輸入問題。

## 生圖模式（須先安裝生圖 runtime）

- 生圖模式：直接進入動漫生圖；也可直接說「幫我畫……」，不用先切換模式。
- 舊「快速生圖模式」指令會改用動漫模式，不再使用快速模型。
- 動漫模式：高品質動漫 profile。
- 真人模式：攝影 profile。
- 直接描述畫面；附圖後描述要改的部分。
- 結束這張圖：清除上一張延續狀態，仍留在生圖模式。
- 結束生圖：回一般聊天。

目前模型名、下載方式與適用授權以 Setup-ImageGeneration.ps1 及模型供應者為準。提示遵循、人物細節與尺度沒有品質保證；不可把模式當成取消安全限制的指令。

## 個人助理與行程記憶（Android 預覽版 9）

資料保存在自己的電腦記憶資料庫；已配對手機與電腦共用同一位使用者的資料。不是多使用者隔離服務。生圖提示詞及圖片不會進入個人檔案或行程。明確告知才記錄姓名、工作、偏好；資料衝突時先確認，不會從猜測建立身份。

| 用途 | 可以直接輸入 |
| --- | --- |
| 個人資料 | 我叫小明；我的工作是工程師；我喜歡咖啡 |
| 查看／移除資料 | 查看我的資料；忘記我的工作；忘記我的個人資料 |
| 修改資料 | 再說一次新資料，看到差異後說「確認更新」 |
| 行程 | 明天下午三點要開會；我明天要幹嘛；查看行程 |
| 修改／取消行程 | 修改行程 編號 改到後天15:00；取消行程 編號 |
| 待辦 | 新增待辦 明天15:00 繳費；查看待辦；逾期待辦 |
| 完成／修改 | 完成待辦 編號；修改待辦 編號：後天15:00 繳費；查看已完成待辦 |
| 專案 | 新增專案 網站；專案進度 網站：設計完成；查看專案 |
| 會議紀錄 | 會議筆記 週會：先完成登入頁；查看會議；搜尋筆記 登入 |
| 修改會議筆記 | 修改會議 編號：更新後的完整內容 |
| 每日習慣 | 新增習慣 每天09:00 喝水；打卡 喝水；查看習慣 |
| 修改習慣 | 修改習慣 編號：10:00 喝水 |
| 移除記事 | 刪除待辦 編號；刪除專案 編號；刪除會議 編號；刪除習慣 編號 |
| 提醒 | 提醒我 明天15:00 出門；查看提醒；關閉助理提醒；開啟助理提醒 |
| 摘要與出門準備 | 今天摘要；明天摘要；出門摘要；助理說明 |

表格內分號表示不同訊息，每次只輸入一條。編號使用回覆方括號中的八個字元；也可用唯一且完全相同的項目名稱指定待辦、專案、會議、習慣。

日期使用電腦系統時區，可用 DAILY_TIMEZONE=Asia/Taipei 指定。相對日期在保存時轉為實際日期；不明確的上午／下午會再詢問。使用 15:00 這類 24 小時時間可避免歧義。行程一次記一個開始時間，跨日、全天與重複行程請使用原本 .ics 匯入功能；每日習慣目前只支援每天一次。

到時提醒每 15 秒檢查，電腦後端必須開著。未指定時間不會擅自設定鬧鐘。當日行程、已到期的定時待辦與當日習慣會提醒，同一項目在相同日期／時間不重複提醒。電腦關機期間無法通知；重新開啟會補當日行程及未完成到期待辦，不補過去日期的行程。

手機需要預覽版 9、保持配對連線並允許通知。通知出現在系統通知列，不會打開對話框；手機關閉或離線時無法保證準時，重新連線僅接收最近 24 小時的通知。Android 省電或背景限制可能延遲通知。關閉助理提醒停止產生新提醒，已產生的通知紀錄仍保留。

今天／出門摘要查詢目前天氣和短時間降雨預報；明天摘要只列實際已記錄事項。手機只使用手機提供的位置，缺少位置時請說「更新手機位置」。不會猜天氣或自動估算交通出發時間。專案進度和會議筆記由明確指令保存；不會自動錄音，也不會自動替你發信或修改外部日曆。文件上傳、摘要與搜尋沿用原本文件庫功能。

移除個人資料／記事不等於清除歷史聊天。記憶宮殿頁面可以查看個人檔案、行程和助理記事。

新聞搜尋：需先配置搜尋 API；未設定時清楚提示，不會自動啟動本機搜尋引擎。摘要及標題不能當成讀過全文。
