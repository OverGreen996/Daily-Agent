# 對話指令與操作

以下為目前程式的明確命令。一般聊天、搜尋、讀圖可自然提問；設定命令若沒反應，先照表輸入。PC 原生介面命令與 Android 命令不同。LLM 自然語言工具呼叫仍可能失敗，不代表每種表述都是固定命令。

## 電腦：外觀與泡泡

| 功能 | 指令或操作 |
|---|---|
| 活動區域 | 框選活動區域／設定活動區域；也可右鍵框選 |
| 移動 | 自由走動／開始走動；停止走動／留在原地 |
| 自主動作 | 開啟自主動作／關閉自主動作 |
| 手動動作 | 揮手／打招呼、跳一下／跳一跳、左右張望／四處看看 |
| 滑鼠跟隨 | 右鍵設定開關；16 方向不用於自動隨機動作 |
| 更換皮膚 | 右鍵設定中的外觀匯入，選透明 PNG／WebP 或 v2 ZIP |
| 傳送皮膚 | 傳送外觀到手機／把寵物傳到手機 |
| 歷史 | 右鍵設定開啟／關閉歷史模式 |
| 關閉 | 右鍵可僅關閉桌寵，或關閉桌寵並停止背景服務 |
| 圖片另存 | 儲存剛才的圖片／保存剛才的圖片；點縮圖放大 |

## 電腦：語音

其他泡泡／外觀命令：更換寵物形象、載入寵物形象、換回露米、使用內建露米；顯示歷史對話／開啟歷史對話／查看對話紀錄；隱藏歷史對話／關閉歷史對話；展開對話／查看詳細；縮小對話／回到泡泡；收起對話／隱藏對話／收起泡泡；保持置頂／取消置頂；停止動畫／恢復動畫；看著滑鼠／停止跟隨滑鼠；變大一點／變小一點；泡泡半透明／泡泡不透明；移除圖片／取消圖片／移除文件／取消文件／取消附件；關閉桌寵／退出桌寵。

- 開啟麥克風／開始聆聽／開啟語音。
- 關閉麥克風／停止聆聽／關閉語音。
- 語音回覆開關與裝置：右鍵設定；麥克風與播放裝置分開選。
- 測試麥克風／測試收音；測試語音播放／測試喇叭。
- 停止朗讀／停止說話／安靜。
- 使用Kokoro語音；使用Windows語音。
- 使用zf_001聲線（其他支援的聲線由設定選；不保證任意編號存在）。
- 語速快一點／說快一點；語速慢一點／說慢一點。
- 語速正常／恢復正常語速；語速1.2倍。
- 開啟通知提醒／關閉通知提醒（需 Windows 授權／套件身分）。

## Agent 狀態與 Idle

- 查看狀態／顯示目前狀態。
- 查看搜尋狀態。
- 進入待機／休息一下／讓露米休息。
- 開啟天氣提醒／關閉天氣提醒；開啟天氣通知／關閉天氣通知。
- 天氣更新間隔改成10分鐘（支援10、15、20）。
- 開啟環境觀察／關閉環境觀察。
- 開啟陌生軟體查詢／關閉陌生軟體查詢。
- 開啟畫面觀察／關閉畫面觀察（低頻截圖與 OCR）。
- 開啟定時畫面觀察／關閉定時畫面觀察（同一設定）。
- 開啟高階畫面觀察／關閉高階畫面觀察（按需使用完整模型；啟用時亦開低頻畫面觀察）。
- 開啟記憶閒聊／關閉記憶閒聊。
- 看看我在做什麼／看一下畫面／看看目前畫面（手動低解析度觀察）。

一般問「今天天氣？」即可查詢；主動提醒需要另行開啟。5 分鐘未互動進 Idle，搭話還要經過事件分數、冷卻及去重，不是每5分鐘一定說一句。

## 記憶宮殿

- 查看記憶宮殿：泡泡列出摘要；PC「打開記憶宮殿／開啟記憶書架」打開管理頁。
- 記住：我喜歡簡短回答。
- 記住偏好：內容；記住規則：內容；記住決定：內容。
- 查看永久記憶；查看永久記憶第2頁。
- 搜尋永久記憶：關鍵字。
- 修改記憶 編號：新內容。
- 刪除記憶 編號（僅移除 pin，原始聊天仍保存）。
- 查看記憶衝突；使用新記憶 編號；保留舊記憶 編號。

編號取自查詢結果。生圖指令／prompt 不寫入記憶宮殿；圖片檔本身不因此刪除。

## 網頁、文件、基本工具

- 幫我搜尋最新 AI 新聞，附上來源。
- 閱讀 https://example.com 並摘要。
- 搜尋本機檔案 關鍵字（僅允許範圍內）；讀取檔案、開啟記事本、剪貼簿、系統資訊由 ToolBroker 管控，並非任意 Shell。
- 拖入圖片／貼上圖片，再輸入問題。
- 拖入 TXT、Markdown 或 PDF，問「幫我完整摘要這份文件」。限制：5 MB、PDF 50頁，掃描 PDF 需要 Windows OCR。
- 查看文件庫；查看文件庫第2頁。
- 搜尋文件：關鍵字；語意搜尋文件：問題。
- 使用文件 編號；使用文件：「完整檔名.pdf」。
- 詢問文件 編號：第2頁說了什麼？
- 比較文件 檔名A、檔名B：有哪些差異？
- 查看目前文件；結束文件閱讀／收起文件。
- 拖入 `.ics` 匯入行事曆；查看行事曆；開啟行事曆提醒／關閉行事曆提醒；清除行事曆。

## 生圖模式（須先安裝生圖 runtime）

- 生圖模式：進入生圖對話。
- 動漫模式：高品質動漫 profile。
- 真人模式：攝影 profile。
- 直接描述畫面；附圖後描述要改的部分。
- 結束這張圖：清除上一張延續狀態，仍留在生圖模式。
- 結束生圖：回一般聊天。

目前模型名、下載方式與適用授權以 Setup-ImageGeneration.ps1 及模型供應者為準。提示遵循、人物細節與尺度沒有品質保證；不可把模式當成取消安全限制的指令。

## PC 手機連線與共享

- 開啟 Cloudflare 連線：Quick Tunnel 臨時網址。
- 開啟手機配對：啟動入口、取得五分鐘8位碼。
- 查看手機連線；關閉手機連線；解除手機配對／關閉手機配對。
- 分享資料夾 C:\My Files；查看共享資料夾；停止分享資料夾。
- 使用手機位置／使用電腦位置（PC 環境偏好；手機問天氣仍取該手機的位置）。
- 開啟手機位置配對：舊版同網路 GPS 頁，不能代替 Android App。

## Android 專用

- 第一次自動配對頁；或「配對／重新配對」。也可「連線 HTTPS網址 八位碼」。
- 重新連線；查看連線；解除配對。
- 設定／長按寵物；使用說明。
- 同步寵物外觀／更新寵物外觀。
- 開啟桌寵懸浮／關閉桌寵懸浮。
- 開啟通知偵測／關閉通知偵測。
- 更新手機位置。
- 傳圖片／看圖片／選圖片；從相簿分享圖片給 App。
- 搜尋電腦檔案 關鍵字 → 使用檔案 1 → 提問。
- 清除附件。
- 查看歷史對話／開啟歷史紀錄模式；關閉歷史紀錄模式。
- 儲存圖片／保存圖片；縮圖點擊放大、雙指縮放、長按儲存。
- 關閉桌寵。

Android 不具備 PC 任意程式啟動、任意 Shell、PC 剪貼簿與未分享檔案讀取權限。
