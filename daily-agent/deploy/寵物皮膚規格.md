# Daily Agent 自訂皮膚標準 v2

本規格對應 `desktop/PetAppearance.cs`、`desktop/PetBehavior.cs` 與 Android PetAnimationRules；不是未實作的新格式。可用自己的圖，但必須有使用／散布權利。

## A. 靜態皮膚

匯入真正帶 Alpha 透明背景的 PNG 或 WebP。不能只把背景畫成棋盤格；JPG 不支援去背。必須同時有可見像素及完全透明像素。單檔最多32 MB、最大邊8192像素、總像素不超過16,777,216。推薦192×208或同比例倍數。靜態皮膚不能自動補出完整動作。

## B. 動畫 ZIP

```text
my-pet.zip
├─ pet.json
└─ spritesheet.png
```

也可單一子資料夾包含這兩個檔案。ZIP 只能有一個 pet.json；圖片路徑相對它，禁止絕對路徑與 `..`。圖集可用 PNG／WebP，優先無損 PNG。pet.json 最多64KB，圖集解壓後最多32MB。不要把 PSD、模型、程式或其他寵物一起塞進包裡。

```json
{
  "id": "my-pet",
  "displayName": "我的桌寵",
  "chatName": "小米",
  "description": "角色說明",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.png"
}
```

顯示名稱優先 chatName，再 displayName，最長64字元。description 不是任意系統指令；不會自動安裝腳本或改 Agent 權限。匯入後由程式分配內部ID。

## C. 圖集尺寸與動作位置

固定 **8欄 × 11列**，每格比例 **192:208（12:13）**，推薦整圖 **1536×2288**。不能加格線、間隔、外框或文字。所有格子相同大小，從左到右放影格。

下表列號用1起算（程式索引用0起算）：

| 列 | 名稱 | 有效影格／格子 | PC 每格時間 |
|---|---|---|---|
| 1 | idle | 第1～6格；第7格可放獨立中性姿勢；第8格透明 | 250ms |
| 2 | running-right | 8格向右移動 | 100ms |
| 3 | running-left | 8格向左移動 | 100ms |
| 4 | waving | 前4格揮手 | 150ms |
| 5 | jumping | 前5格跳躍 | 150ms |
| 6 | failed | 8格失敗／失落 | 180ms |
| 7 | waiting | 前6格等待／提醒 | 180ms |
| 8 | running | 前6格處理中／思考／搜尋 | 180ms |
| 9 | review | 前6格檢視動作 | 180ms |
| 10 | look-upper | 8個方向姿勢，方向0～7 | 方向選格 |
| 11 | look-lower | 8個方向姿勢，方向8～15 | 方向選格 |

各列未用到的保留格須**完全透明**。必填格不可全透明；必填格及中性格不得超過95%像素非透明。第1列第7格不是 idle 循環的一部分。

動作語意必須一致：failed 只用於失敗；第8列是處理中，不是隨機裝飾。自動小動作輪替目前是揮手與跳躍；16方向不納入自動輪替。

## D. 16方向

0為正上，順時針每22.5度一格；4正右、8正下、12正左。方向 d 的列是第 `10 + floor(d/8)` 列，欄是第 `1 + d%8` 格。

第10列：上、右上偏上、右上、右上偏右、右、右下偏右、右下、右下偏下。
第11列：下、左下偏下、左下、左下偏左、左、左上偏左、左上、左上偏上。

這些是凝視方向，不是16格轉圈動畫。跟隨滑鼠時依游標相對寵物的位置選格；處理中等狀態優先。

## E. 繪製與驗收

1. 全影格保持相同角色比例、腳底基準及中心位置，避免動畫跳動。
2. 耳朵、角、尾巴與特效不得超出單格或串到鄰格；跳躍預留頭頂空間。
3. 使用透明底、乾淨邊緣；陰影也應帶Alpha。不要烘焙聊天泡泡與名字。
4. 建議先做192×208單格驗證，再組圖；不要依視覺估算格子邊界。
5. 打包後在桌寵右鍵設定中匯入，測試揮手、跳躍、左右走動、處理中、失敗與滑鼠四個主方向。
6. PC 說「傳送外觀到手機」，手機說「同步寵物外觀」。不需要在手機重新畫圖；傳輸會驗證素材。

匯入器會檢查尺寸、透明度、空白格與缺格，但不會判斷畫得像不像、動作是否流暢；仍需要人工觀看。

開發者原生測試（原始碼根目錄，需要Windows SDK）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\desktop\Build-Pet.ps1 -SelfTest
```

這會測試內建驗证／動畫行為；自己的皮膚仍需實際匯入驗收。範本 JSON 見本文件，不包含對使用者私人圖片的自動上傳。
