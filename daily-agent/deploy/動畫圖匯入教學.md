# 把 GPT 生成的整張動畫圖變成寵物

這是尚未發布的本地開發功能；等 XNG 完成後一起驗收、發布。

## 使用順序

1. 右鍵桌寵 →「外觀與動作」→「寵物外觀編輯器」。也可從「功能與設定 → 連線與維護」開啟。
2. 按「匯入整張 GPT 動畫圖，自動整理」，或把整張 PNG、JPG、WebP 拖到左側預覽區。
3. 程式自動偵測欄列、切影格、清除邊界相連背景，並播放每列動作。標準 8×11 圖採用既有排列；其他排列可用本地 Qwen 看圖辨識動作。模型不確定時顯示 `unknown`，可在表格修改。
4. 按「組裝成動畫，進入預覽」。預設統一同一動作的比例、對齊位置，跳躍保留原有高度變化。可選擇依輪廓相似度建議重新排序；跳躍和轉頭不重排。
5. 在「動畫預覽」切換動作、播放檢查，再按「儲存為新外觀並套用」。也能匯出透明 PNG 精靈圖的 v2 ZIP，之後匯入其他安裝。
6. 桌寵右鍵 →「傳送外觀到手機」，傳到已配對 APK。

獨立開啟編輯器時，儲存後到桌寵「更換寵物形象」選用新外觀。使用中的原外觀與原圖都保留。動作縮圖不會上傳到雲端、寫入對話或記憶宮殿；儲存的皮膚留在自己的寵物庫。

## 怎樣的原圖最好處理

每列是一個動作、每欄是一個連續影格。角色之間保留空白，不要重疊，使用單色背景或真正透明背景，避免把說明文字、格線畫進角色旁。可以直接請 GPT 依 [寵物皮膚規格](寵物皮膚規格.md) 生成。

標準排列是 8 欄、11 列；動作依序為待機、向右跑、向左跑、揮手、跳躍、失敗、等待、忙碌、閱讀，再加上下兩列共 16 個轉頭方向。每列影格數及保留格依 `desktop/pet-format-v2.json`；保留格會清空。

如果自動切錯，在匯入視窗填寫實際欄／列數，按「重新分析」。複雜背景、標題列、重疊角色可能需要先裁切原圖或用微調工具清理。去背只處理與邊界相連的背景色，避免刪掉封閉的白色眼睛、衣服；照片或複雜場景不是目前的一鍵去背範圍。

## 連貫與缺圖

程序會檢查相鄰影格的輪廓變化，標示可能跳格；對齊可以改善角色忽大忽小、基準位置偏移。影格不足時會取樣或重複現有影格，缺少動作可以明確勾選「暫用待機」，結果會列出哪些動作用了替代影格。

這些處理不會生成新的姿勢，不能保證修好 AI 畫錯的手腳、不同影格變臉或缺失的中間動作。那類問題應回 GPT 補圖，再重新匯入；編輯器的畫筆、橡皮擦和復原可處理小範圍瑕疵。

## 本地動作辨識

辨識非標準排列時，Daily Agent 背景服務需已啟動，且「模組管理器 → 寵物動畫圖分析」已啟用。使用現有聊天模型的看圖能力，不額外下載生圖模型。服務沒開、模型忙碌或辨識失敗時，去背與切格仍可使用，動作名稱可手動指定。

開發者可用以下指令開啟獨立編輯器，不需要先下載模型：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Open-PetEditor.ps1
```

完整自動辨識的準確度仍需以你的 GPT 動畫圖實測；目前已測試標準整圖分格、白底去背、非標準欄列、對齊、缺圖提示、匯出與重新匯入。神經模型的分類測試使用模擬回覆，未把它當成真人工審核的準確度驗證。
