# Daily Agent 安裝與操作手冊

[← 回首頁](../../README.md) · [先完成基本流程](../docs/快速開始.md) · [對話指令](對話指令.md) · [現版本介紹](../docs/現版本介紹.md)

本版：Windows 0.2.2／Android Preview 10。桌面是去背寵物與聊天泡泡。手機不安裝模型，必須連回開著的電腦。首次安裝模型需要網路；空間取決於所選功能；發布包不含個人記憶、配對資訊、私密設定或模型。

## 1. 電腦安裝（一般使用者）

**先完成三步即可使用：下載 `DailyAgent-Setup.exe` → 按「安裝並開始使用」→ 等桌寵出現。** 不必先讀後面的 PowerShell 或 Cloudflare 教學。

基本版首次預留約 **12 GB 暫時空間**，含下載、解壓縮和待機模型轉換；完成後會清除可安全移除的轉換來源。這不是每次啟動需要下載的大小。生圖與語音由使用者在「補裝功能」另行勾選，視窗會顯示預估額外空間和磁碟剩餘空間。

| 畫面／問題 | 只需做什麼 |
| --- | --- |
| 正在下載，百分比在增加 | 繼續等待，可以最小化視窗 |
| 網路中斷、程式關掉或重開機 | 開桌面「Daily Agent 功能與設定」→「繼續下載／修復」 |
| 空間不足 | 按安裝器「變更安裝位置」，或取消不需要的選配 |
| 不知道需要裝哪些功能 | 先只用基本版；需要語音、生圖時再勾選 |
| 生圖不支援顯示卡 | 基本版照常用；本地生圖需 NVIDIA 驅動及至少 8 GB 顯存，建議 12 GB |
| 找不到 ZIP／sha256 | 改用單檔 EXE；不用自己準備這些檔案 |
| 手機尚未連線 | 先完成電腦基本安裝，再從「連線與維護」配對 |

下載支援續傳；不支援續傳的下載站會自動改為重新下載該檔案，完整檔案通過校驗才會啟用。更新與修復保留個人資料。安裝器不會覆蓋使用者選到的其他非空資料夾。

設定入口是 **Daily Agent 功能與設定**，分成四個頁籤：

| 頁籤 | 用途 |
| --- | --- |
| 開始使用 | 基本模型準備、中文進度、開始聊天 |
| 補裝功能 | 勾選需要的額外下載；已存在的資源沿用 |
| 模組管理器 | 啟用／停用功能，查看載入狀態及相依關係；儲存後完整關閉並重開生效 |
| 連線與維護 | 手機配對、記憶宮殿、清理安裝暫存、卸載 |

基本聊天、記憶與行程不需要下載生圖或安裝 Docker／Cloudflare。停用模組不會刪除資料或模型。插件開發、替換或移除功能請看 [架構文件](../ARCHITECTURE.md)。

Google 登入與 Drive 備份的設定在「連線與維護 → Google Drive 備份」，也可從記憶宮殿打開。第一次要先申請 Desktop OAuth 用戶端，步驟見 [Google Cloud 中文教學](GoogleDrive備份教學.md)；預設不自動上傳記憶。

1. 到 [最新版下載頁](https://github.com/OverGreen996/Daily-Agent/releases/latest) **只下載 DailyAgent-Setup.exe**。
2. 雙擊，按 **安裝並開始使用**。不需另外下載 ZIP、校驗檔、Node 或輸入 PowerShell 指令。
3. 保留「安裝後自動準備基本功能」勾選，等待「功能與設定」視窗準備模型。完成後桌寵啟動；語音、生圖等額外功能之後在「補裝功能」勾選下載。

預設只勾基本功能；所需空間依勾選項目而定，目前配置以 Windows x64 與 NVIDIA 12 GB 顯存為基準。安裝程式尚未簽章，Windows 可能顯示未知發行者。網路搜尋請在「模組管理器 → 搜尋 API 與輪替」設定自己的金鑰。

**中斷或重開機後：雙擊桌面 Daily Agent 功能與設定 繼續。平時使用：雙擊 Daily Agent。** 已有下載會沿用，不必重新安裝。相同版本重跑會核對程式後繼續配置。

安裝到 `%LOCALAPPDATA%\DailyAgent`。手機配對、Cloudflare 帳號與網域在桌寵啟動後再設定，不影響本地安裝。每位使用者使用自己的帳號，不用作者的網域。

遇到舊版「找不到 DailyAgent-Windows.zip.sha256」：改下載最新版單檔 Setup，不需要自己建立校驗檔。`DailyAgent-Windows.zip` 留給更新工具；一般使用者不必下載。`DailyAgent-Installer.zip` 是同一個單檔 Setup 加中文教學的備用壓縮包。

偏好指令時，也可在一般 PowerShell 貼上：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Setup-DailyAgent.ps1"
```


安裝包已附 Node，ComfyUI 包含 Python。NVIDIA 驅動、Windows OCR 語言、Cloudflare 個人帳號／網域、手機配對及 Android 安裝授權仍由使用者設定。若系統缺 Microsoft App Installer（winget），先到 Microsoft Store 補裝，再按 Setup。不要同時啟動原始碼版與安裝版，兩者使用同一個本機連接埠。

僅沿用本安裝目錄既有資源；其他開發資料夾的模型不會自動搬移或刪除。完整配置成功後會啟動桌寵。進度存於安裝目錄 `runtime/full-setup.json`；失敗時保留視窗中的錯誤以便排除。

原始碼版：雙擊專案根目錄 **Setup-All-DailyAgent.cmd**，需已有 Node 24+。唯讀檢查（不下載、不修改）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-All-DailyAgent.ps1 -CheckOnly
```

啟動：雙擊桌面「Daily Agent」，或：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Launch-DailyAgent.ps1"
```

結束：桌寵右鍵 → 關閉桌寵（停止背景服務）。僅關閉桌寵的選項會保留後端。

PowerShell 的 Bypass 只用於這次程序；不需要永久調低整台電腦的執行原則。

## 2. 後續指令先定位目前安裝目錄

以下「額外功能」指令都先在 PowerShell 執行這段；這樣更新版本後也不必手改路徑：

```powershell
$dailyInstall = Join-Path $env:LOCALAPPDATA 'DailyAgent'
$dailyState = Get-Content (Join-Path $dailyInstall 'current.json') -Raw | ConvertFrom-Json
$dailyRelease = Join-Path $dailyInstall ('releases\' + $dailyState.current)
Set-Location $dailyRelease
```

原始碼版則切到自己 clone 的資料夾，使用根目錄 Start-DailyAgent.ps1，不要與安裝版並行。

## 3. 另外需要安裝哪些東西

| 項目 | 何時需要 | 方式 |
|---|---|---|
| Windows x64、NVIDIA 驅動 | PC GPU 推論 | 安裝 NVIDIA 官方適用驅動；目標硬體 RTX 3080 Ti 12 GB |
| Node runtime | 所有 PC 功能 | 安裝包已附，不用額外裝 Node |
| Ollama 與模型 | 聊天／記憶／Idle | 首次 Setup 自動下載 portable runtime；不需另裝全域 Ollama |
| Kokoro／語音辨識資源 | 語音 | Setup 會處理；也可單獨重跑 Setup-Kokoro.ps1 |
| cloudflared | 手機外網連線 | 一鍵配置會下載；個人連線設定見第 5 節 |
| ComfyUI 與 checkpoint | 本地生圖 | 一鍵完整配置包含；單獨處理見第 6 節 |
| Windows OCR 語言 | 掃描 PDF／低頻 OCR | Windows 設定 → 時間與語言，加入繁中／英文的相關語言功能 |
| Android 8+ | 手機桌寵 | APK；不需要 Python、Node、模型或 Docker |

開發原始碼／修改 C# 需要 .NET Framework 編譯器及 Windows SDK；修改 Android 才需要 JDK/Android SDK。一般使用者使用預編譯安裝包與 APK。



## 4. 網路搜尋 API

網路搜尋使用 Exa、Tavily、Firecrawl，無須下載搜尋引擎或安裝 Docker／WSL。

1. 開啟桌面「Daily Agent 功能與設定」。
2. 在「模組管理器」啟用「網路搜尋」，按「搜尋 API 與輪替」。
3. 填入自己的 API 金鑰，設定順位與用量上限，儲存後檢查狀態。

不用同時申請三家；至少設定一家即可。未設定時會提示搜尋尚未設定，基本聊天與記憶仍可使用。完整說明見 [搜尋 API 與輪替教學](搜尋API與輪替教學.md)。

## 5. 手機配對與 Cloudflare

### 免費測試連線：不需要網域

先執行第 2 節，再執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-MobileBridge.ps1
```

電腦桌寵輸入「開啟 Cloudflare 連線」，得到 HTTPS 網址與 APK 下載網址。手機安裝 APK，第一次開啟會出現配對頁。電腦說「開啟手機配對」，手機填 HTTPS 網址與 8 位碼（5 分鐘有效）。
Quick Tunnel 重建時網址會改；手機長按寵物進設定重新配對／換網址。瀏覽器開首頁沒有聊天介面是正常的。

### 固定網址（需要自己的網域）

1. Cloudflare 註冊／登入，Add a domain 輸入自己的根網域，選 Free。
2. 回註冊商 Nameservers，替換成 Cloudflare 分配的兩個值，不能抄別人的。
3. 等 Cloudflare 網域顯示 Active。
4. Cloudflare → Networking → Tunnels，建立 tunnel，選 cloudflared／Windows。
5. 已裝 portable cloudflared 後，用**系統管理員 PowerShell**執行第 2 節定位，再執行下例。把 `YOUR_TUNNEL_TOKEN` 換成控制台提供的 token；不要把 token 上傳 Git 或貼公開截圖。

```powershell
& .\.daily-runtime\cloudflared\cloudflared.exe service install YOUR_TUNNEL_TOKEN
```

6. Published application route：例如 `pet.你的網域.xyz`，Service 選 HTTP，URL 填 `127.0.0.1:3221`。
7. 電腦桌寵說「開啟手機配對」啟動 3221 並取得碼；手機填自己的固定 HTTPS 網址與配對碼。

固定 Tunnel 的 Windows 服務與程式內 Quick Tunnel 是不同機制。固定連線不用說「開啟 Cloudflare 連線」。目前 PC 重開／Agent 重啟後仍需啟動手機入口；固定 tunnel 存在不代表 3221 已在聆聽。

手機圖片：相簿分享給日常桌寵，或說「傳圖片」。生成結果點擊放大、雙指縮放，長按或說「儲存圖片」。輕點寵物開／收對話，長按開設定；「寵物大小」拉條可調 40%～200%，也可雙指縮放。天氣／附近問題使用手機定位，失敗時不回退家中 PC。

以下先執行第 2 節定位。生圖 runtime 與 checkpoints 很大，請預留數十 GB，依模型授權使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-ImageGeneration.ps1
```

只裝 ComfyUI、不下載預設模型：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-ImageGeneration.ps1 -SkipModel
```

語音重裝／修復：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-Kokoro.ps1
```

桌寵右鍵設定可選麥克風、播放裝置、TTS 引擎與聲線。先說「測試麥克風」「測試語音播放」。啟用語音回覆才暖機。自動搭話不朗讀。
Windows 通知若提示需要套件身分，依 `desktop/notification-package/README.md` 操作；不是開啟開關就保證取得 Windows 授權。Android 設定需手動授予通知存取、懸浮與必要定位權限。

## 7. OTA 更新／回復

版本資訊：https://github.com/OverGreen996/Daily-Agent/releases/latest/download/update.json

只檢查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Update-DailyAgent.ps1"
```

下載、驗證並安裝新版本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Update-DailyAgent.ps1" -Install
```

完成後重新啟動桌寵。模型、記憶資料與既有 `.env.local` 會保留。回復上一個已安裝版本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Launch-DailyAgent.ps1" -Rollback
```

回復的是程式，不是資料庫備份。Android OTA 介面是 `GET https://你的手機入口/v1/updates?versionCode=10`，填入手機目前版本；回傳版本、大小、SHA-256、簽章指紋、APK 路徑及 `requires_reinstall`。目前尚未做 App 自動更新 UI；手機端安裝由 Android 確認。

手機掃描安裝器的 QR Code，直接從 GitHub 下載 APK，電腦安裝包不再內附 APK。安裝後也可在「功能與設定 → 連線與維護 → 手機 APK｜掃碼下載」重新顯示 QR Code。APK 下載不依賴電腦或 Cloudflare，實際聊天與生圖仍需連回電腦。舊 PC 的 `/download/android.apk` 入口會轉向 GitHub。

Preview 10 已改用固定的新簽章。第一次安裝直接下載 APK 並安裝；手機已有 Preview 9 或更舊版時，先記下自己的電腦連線網址，移除舊桌寵，再安裝 Preview 10。在電腦產生新配對碼，手機重新配對並依畫面授權懸浮窗及通知。電腦記憶宮殿保留，手機的舊配對與設定會清除。Preview 10 之後沿用同一把金鑰，下載新版 APK 即可覆蓋更新。

## 8. 故障排除與資料

- 指令碼禁止執行：用教學中的 `powershell -NoProfile -ExecutionPolicy Bypass -File ...`，不要直接輸入 `.\xxx.ps1`。
- 找不到腳本：先做第 2 節定位；原始碼與安裝版路徑不同。
- 手機 502：檢查電腦開著、桌寵說「開啟手機配對」，確認 tunnel 指向 3221。
- 手機 401：重配對；不要使用過期的一次性碼。
- 無語音：先確認播放裝置、語音回覆開關，再測試；不要只看麥克風音量指示。
- 模型未下載：重跑首次 Setup。Idle CPU-only，不應常駐 GPU 主模型。
- 一般泡泡 15 分鐘收起；開啟歷史模式可保留。重開不自動播放上次話語。
- 安裝版記憶 `%LOCALAPPDATA%\DailyAgent\data`，模型／寵物設定在 `runtime`；備份前先正常關閉程式。
- 本版未完成 Android 真機完整驗收；固定 Cloudflare tunnel 需由帳號持有人完成配置。

進階對話指令見「對話指令.md」，皮膚製作見「寵物皮膚規格.md」。

## 9. 原始碼建置（開發者）

從 GitHub clone 本專案後，在專案根目錄開 PowerShell。先安裝 Node.js 24+（https://nodejs.org/），C# 編譯另需 Windows SDK（https://developer.microsoft.com/windows/downloads/windows-sdk/）。套件管理器若被 PowerShell 限制可用 npm.cmd：

```powershell
Set-Location .\daily-agent
npm.cmd ci
npm.cmd test
Set-Location ..
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-DailyAgent.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-DailyAgent.ps1
```

Android 工具只供編譯／ADB，不是手機使用者必需：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\android\Setup-AndroidTools.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\android\Test-Android.ps1 -Build
```

Android 簽章金鑰獨立保存在 `%LOCALAPPDATA%\DailyAgentBuildKeys`，不放在可清除的 runtime。每次建置會校驗並私密備份到「文件\DailyAgent-簽署金鑰備份」；請另複製到離線磁碟，勿上傳 Git。固定金鑰遺失時必須還原備份，不會自動換另一把金鑰。更換金鑰無法覆蓋原簽章 APK；只有明確決定重裝時才執行 `Build-Android.ps1 -Rekey`，並提高 versionCode。簽章私鑰及恢復密碼不隨原始碼或安裝包發布。

原生桌寵檢查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\desktop\Build-Pet.ps1 -SelfTest
```

Windows 通知身分選用安裝（先關閉桌寵；會信任本機產生的 CurrentUser 憑證並註冊身分）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\desktop\notification-package\Enable-Identity.ps1
```

詳見同目錄 README 的撤銷方式；不要刪除其他程式的憑證。



## 個人助理與行程記憶

資料保存在自己的電腦記憶資料庫；已配對手機與電腦共用同一位使用者的資料。不是多使用者隔離服務。生圖提示詞及圖片不會進入個人檔案或行程。明確告知才記錄姓名、工作、偏好；資料衝突時先確認，不會從猜測建立身份。

| 用途 | 可以直接輸入 |
| --- | --- |
| 個人資料 | 我叫小明；我的工作是工程師；我喜歡咖啡 |
| 查看／移除資料 | 查看我的資料；忘記我的工作；忘記我的個人資料 |
| 修改資料 | 再說一次新資料，看到差異後說「確認更新」 |
| 行程 | 明天下午三點要開會；我明天要幹嘛；查看行程 |
| 修改／取消行程 | 修改行程 編號 改到後天15:00；取消行程 編號 |
| 待辦 | 新增待辦 明天15:00 繳費；查看待辦；逾期待辦 |
| 完成／修改 | 完成待辦 編號；修改待辦 編號：後天15:00 繳費；查看已完成待辦 |
| 專案 | 新增專案 網站；專案進度 網站：設計完成；查看專案 |
| 會議紀錄 | 會議筆記 週會：先完成登入頁；查看會議；搜尋筆記 登入 |
| 修改會議筆記 | 修改會議 編號：更新後的完整內容 |
| 每日習慣 | 新增習慣 每天09:00 喝水；打卡 喝水；查看習慣 |
| 修改習慣 | 修改習慣 編號：10:00 喝水 |
| 移除記事 | 刪除待辦 編號；刪除專案 編號；刪除會議 編號；刪除習慣 編號 |
| 提醒 | 提醒我 明天15:00 出門；查看提醒；關閉助理提醒；開啟助理提醒 |
| 摘要與出門準備 | 今天摘要；明天摘要；出門摘要；助理說明 |

表格內分號表示不同訊息，每次只輸入一條。編號使用回覆方括號中的八個字元；也可用唯一且完全相同的項目名稱指定待辦、專案、會議、習慣。

日期使用電腦系統時區，可用 DAILY_TIMEZONE=Asia/Taipei 指定。相對日期在保存時轉為實際日期；不明確的上午／下午會再詢問。使用 15:00 這類 24 小時時間可避免歧義。行程一次記一個開始時間，跨日、全天與重複行程請使用原本 .ics 匯入功能；每日習慣目前只支援每天一次。

到時提醒每 15 秒檢查，電腦後端必須開著。未指定時間不會擅自設定鬧鐘。當日行程、已到期的定時待辦與當日習慣會提醒，同一項目在相同日期／時間不重複提醒。電腦關機期間無法通知；重新開啟會補當日行程及未完成到期待辦，不補過去日期的行程。

請使用目前發布的手機 Preview 10，保持配對連線並允許通知。通知出現在系統通知列，不會打開對話框；手機關閉或離線時無法保證準時，重新連線僅接收最近 24 小時的通知。Android 省電或背景限制可能延遲通知。關閉助理提醒停止產生新提醒，已產生的通知紀錄仍保留。

今天／出門摘要查詢目前天氣和短時間降雨預報；明天摘要只列實際已記錄事項。手機只使用手機提供的位置，缺少位置時請說「更新手機位置」。不會猜天氣或自動估算交通出發時間。專案進度和會議筆記由明確指令保存；不會自動錄音，也不會自動替你發信或修改外部日曆。文件上傳、摘要與搜尋沿用原本文件庫功能。

移除個人資料／記事不等於清除歷史聊天。記憶宮殿頁面可以查看個人檔案、行程和助理記事。



## 自選功能與卸載

先按「安裝並開始使用」完成基本版，再到「功能與設定 → 補裝功能」勾選需要的額外資源。語音朗讀、中文語音輸入、瀏覽器、動漫生圖、真人生圖、Cloudflare 外網手機連線都可分開勾選。兩種生圖共用 ComfyUI，只選一種就不下載另一種，也不額外下載舊快速動漫模型。每種生圖約 7 GB 模型，運行環境與暫存另計。

之後雙擊桌面 **Daily Agent 功能與設定** 可重選、補裝或重試，會記住上次勾選。不勾只表示本次不配置，不會刪掉原有功能。同 Wi-Fi 手機配對不需要勾 Cloudflare；外網連線仍需自己的帳號及網域。

卸載：Windows「已安裝的應用程式」找到 Daily Agent，或雙擊桌面 **Daily Agent Uninstall**。確認視窗可勾選「保留記憶宮殿」（預設勾選）。卸載會刪除這套安裝的程式、模型、下載暫存、生成圖片、設定、手機憑證及捷徑。保留時只留下 data/palace.sqlite 與 SQLite WAL 相關檔案（含對話記憶、喜好、行程及助理資料），重裝至同位置可沿用；取消勾選則一併刪除。

只移除位於本安裝目錄的程式與服務；服務若需管理員權限請以管理員執行卸載。其他程式的搜尋服務、Docker、WSL、瀏覽器及顯卡驅動不會刪除；下載資料夾中的安裝檔也不會動。

搜尋現況（2026-10-05）：本機搜尋核心、下載插件及其安裝／更新入口已退役。Daily Agent 不再安裝 Docker 搜尋容器，也不會重建舊引擎。聊天、記憶、行程、生圖、手機連線與公開網頁讀取保留；未設定搜尋 API 時明確顯示「搜尋尚未設定」。搜尋已改為 Exa → Tavily → Firecrawl 的順位與額度輪替，需設定自己的金鑰；各程式各自保存搜尋設定與資料。
