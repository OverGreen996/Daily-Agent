# Daily Agent 安裝與操作手冊

本版：Windows 0.2.1／Android Preview 7。桌面是去背寵物與聊天泡泡。手機不安裝模型，必須連回開著的電腦。首次安裝模型需要網路與大量 SSD 空間；發布包不含個人記憶、配對資訊、私密設定或模型。

## 1. 電腦安裝（一般使用者）

1. 從 GitHub Releases 下載 `DailyAgent-Installer.zip`，完整解壓縮。
2. 同一資料夾內保留 `DailyAgent-Setup.exe`、`DailyAgent-Windows.zip` 和 `.sha256`，雙擊 Setup。
3. 預設裝到 `%LOCALAPPDATA%\DailyAgent`，建立桌面捷徑。Setup 尚未做商業程式碼簽章，Windows 可能提示未知發行者。
4. 安裝完成選「是」，自動開始**一鍵完整配置**。若選「否」，之後雙擊桌面 **Daily Agent Setup**。不用逐條输入指令。
5. 全新配置建議預留約 **60 GB SSD 空間**。若 Windows 要求管理員授權或 Docker 顯示初次條款，依畫面處理。若要求重開機，重開後再按同一個 Setup 捷徑。

偏好指令時，也可在一般 PowerShell 貼上：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Setup-DailyAgent.ps1"
```

完整配置會處理 portable Ollama、Qwen3.5 4B、CPU Idle Q4、embeddinggemma、tokenizer、Kokoro 語音朗讀、中文 Zipformer 語音辨識、瀏覽器、ComfyUI／現行生圖模型／放大模型、cloudflared、Docker／WSL／SearXNG。已安裝的資源沿用，支援的下載使用續傳；某一步失敗會繼續其他步驟，最後列出未完成項目。重跑會重新檢查資源並保留下載。

安裝包已附 Node，ComfyUI 包含 Python。NVIDIA 驅動、Windows OCR 語言、Cloudflare 個人帳號／網域、手機配對及 Android 安裝授權仍由使用者設定。若系統缺 Microsoft App Installer（winget），先到 Microsoft Store 補裝，再按 Setup。不要同時啟動原始碼版與安裝版，兩者使用同一個本機連接埠。

僅沿用本安裝目錄既有資源；其他開發資料夾的模型不會自動搬移或刪除。完整配置成功後會啟動桌寵。進度存於安裝目錄 `runtime/full-setup.json`；失敗時保留視窗中的錯誤以便排除。

原始碼版：雙擊專案根目錄 **Setup-All-DailyAgent.cmd**，需已有 Node 24+。唯讀檢查（不下載、不修改）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-All-DailyAgent.ps1 -CheckOnly
```

啟動：雙擊桌面「Daily Agent」，或：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Launch-DailyAgent.ps1"
```

結束：桌寵右鍵 → 關閉桌寵（停止背景服務）。僅關閉桌寵的選項會保留後端。

PowerShell 的 Bypass 只用於這次程序；不需要永久調低整台電腦的執行原則。

## 2. 後續指令先定位目前安裝目錄

以下「額外功能」指令都先在 PowerShell 執行這段；這樣更新版本後也不必手改路徑：

```powershell
$dailyInstall = Join-Path $env:LOCALAPPDATA 'DailyAgent'
$dailyState = Get-Content (Join-Path $dailyInstall 'current.json') -Raw | ConvertFrom-Json
$dailyRelease = Join-Path $dailyInstall ('releases\' + $dailyState.current)
Set-Location $dailyRelease
```

原始碼版則切到自己 clone 的資料夾，使用根目錄 Start-DailyAgent.ps1，不要與安裝版並行。

## 3. 另外需要安裝哪些東西

| 項目 | 何時需要 | 方式 |
|---|---|---|
| Windows x64、NVIDIA 驅動 | PC GPU 推論 | 安裝 NVIDIA 官方適用驅動；目標硬體 RTX 3080 Ti 12 GB |
| Node runtime | 所有 PC 功能 | 安裝包已附，不用額外裝 Node |
| Ollama 與模型 | 聊天／記憶／Idle | 首次 Setup 自動下載 portable runtime；不需另裝全域 Ollama |
| Kokoro／語音辨識資源 | 語音 | Setup 會處理；也可單獨重跑 Setup-Kokoro.ps1 |
| Docker Desktop + WSL2 | SearXNG 搜尋 | 一鍵配置會安裝／檢查；手動排錯見第 4 節 |
| cloudflared | 手機外網連線 | 一鍵配置會下載；個人連線設定見第 5 節 |
| ComfyUI 與 checkpoint | 本地生圖 | 一鍵完整配置包含；單獨處理見第 6 節 |
| Windows OCR 語言 | 掃描 PDF／低頻 OCR | Windows 設定 → 時間與語言，加入繁中／英文的相關語言功能 |
| Android 8+ | 手機桌寵 | APK；不需要 Python、Node、模型或 Docker |

開發原始碼／修改 C# 需要 .NET Framework 編譯器及 Windows SDK；修改 Android 才需要 JDK/Android SDK。一般使用者使用預編譯安裝包與 APK。

## 4. Docker／SearXNG（免費本機搜尋）

一鍵配置成功後不必重做本節，以下供手動安裝與故障排除。Docker 搜尋服務需要背景運行；重開機後重新按 Setup 即可接續配置。

1. 到 https://www.docker.com/products/docker-desktop/ 下載 Windows Docker Desktop。
2. 使用 WSL2 Linux containers。個人用途選 Personal；登入可以跳過。
3. 若缺 WSL，以系統管理員 PowerShell 執行：

```powershell
wsl --install --no-distribution
wsl --update
wsl --set-default-version 2
```

依 Windows 提示重開機。Docker 不要求另外安裝 Ubuntu。
4. 打開 Docker Desktop，等左下角 Engine running。一般 PowerShell 檢查：

```powershell
docker version
```

應同時有 Client 與 Server。只有 Client／pipe not found 表示 Engine 尚未啟動。
5. 執行第 2 節定位指令，再貼上：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-SearXNG.ps1
```

本機入口 http://127.0.0.1:8888 。脚本會寫入該版本 `.env.local`，保留其他設定。重啟桌寵後說「查看搜尋狀態」、「幫我搜尋最新 AI 新聞，附上來源」。
Docker 必須在背景執行才能搜尋；不用公開 8888。重開 Docker 後容器若沒啟動，重跑 Start-SearXNG.ps1。上游搜尋引擎仍可能限制請求。找不到今天日期不代表搜尋離線。

## 5. 手機配對與 Cloudflare

### 免費測試連線：不需要網域

先執行第 2 節，再執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-MobileBridge.ps1
```

電腦桌寵輸入「開啟 Cloudflare 連線」，得到 HTTPS 網址與 APK 下載網址。手機安裝 APK，第一次開啟會出現配對頁。電腦說「開啟手機配對」，手機填 HTTPS 網址與 8 位碼（5 分鐘有效）。
Quick Tunnel 重建時網址會改；手機長按寵物進設定重新配對／換網址。瀏覽器開首頁沒有聊天介面是正常的。

### 固定網址（需要自己的網域）

1. Cloudflare 註冊／登入，Add a domain 輸入自己的根網域，選 Free。
2. 回註冊商 Nameservers，替換成 Cloudflare 分配的兩個值，不能抄別人的。
3. 等 Cloudflare 網域顯示 Active。
4. Cloudflare → Networking → Tunnels，建立 tunnel，選 cloudflared／Windows。
5. 已裝 portable cloudflared 後，用**系統管理員 PowerShell**執行第 2 節定位，再執行下例。把 `YOUR_TUNNEL_TOKEN` 換成控制台提供的 token；不要把 token 上傳 Git 或貼公開截圖。

```powershell
& .\.daily-runtime\cloudflared\cloudflared.exe service install YOUR_TUNNEL_TOKEN
```

6. Published application route：例如 `pet.你的網域.xyz`，Service 選 HTTP，URL 填 `127.0.0.1:3221`。
7. 電腦桌寵說「開啟手機配對」啟動 3221 並取得碼；手機填自己的固定 HTTPS 網址與配對碼。

固定 Tunnel 的 Windows 服務與程式內 Quick Tunnel 是不同機制。固定連線不用說「開啟 Cloudflare 連線」。目前 PC 重開／Agent 重啟後仍需啟動手機入口；固定 tunnel 存在不代表 3221 已在聆聽。
只轉送 3221；不要轉送桌面管理 3210、Ollama 11435、SearXNG 8888。手機 API 自帶配對授權；Cloudflare 額外互動式登入頁會影響原生 APK，不能未測試就套用。

手機圖片：相簿分享給日常桌寵，或說「傳圖片」。生成結果點擊放大、雙指縮放，長按或說「儲存圖片」。手機長按寵物開設定，雙指縮放寵物。天氣／附近問題使用手機定位，失敗時不回退家中 PC。

## 6. 選用生圖／語音／通知

以下先執行第 2 節定位。生圖 runtime 與 checkpoints 很大，請預留數十 GB，依模型授權使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-ImageGeneration.ps1
```

只裝 ComfyUI、不下載預設模型：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-ImageGeneration.ps1 -SkipModel
```

語音重裝／修復：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-Kokoro.ps1
```

桌寵右鍵設定可選麥克風、播放裝置、TTS 引擎與聲線。先說「測試麥克風」「測試語音播放」。啟用語音回覆才暖機。自動搭話不朗讀。
Windows 通知若提示需要套件身分，依 `desktop/notification-package/README.md` 操作；不是開啟開關就保證取得 Windows 授權。Android 設定需手動授予通知存取、懸浮與必要定位權限。

## 7. OTA 更新／回復

版本資訊：https://github.com/OverGreen996/Daily-Agent/releases/latest/download/update.json

只檢查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Update-DailyAgent.ps1"
```

下載、驗證並安裝新版本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Update-DailyAgent.ps1" -Install
```

完成後重新啟動桌寵。模型、記憶資料與既有 `.env.local` 會保留。回復上一個已安裝版本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Launch-DailyAgent.ps1" -Rollback
```

回復的是程式，不是資料庫備份。Android OTA 介面是 `GET https://你的手機入口/v1/updates`，含 versionCode、size、sha256 與 APK 路徑；目前尚未做 App 自動更新 UI。使用 GitHub Release 或 PC 的 `/download/android.apk` 下載並覆蓋安裝。APK 使用同一把本機 preview key 簽名；手機端安裝由 Android 確認。

## 8. 故障排除與資料

- 指令碼禁止執行：用教學中的 `powershell -NoProfile -ExecutionPolicy Bypass -File ...`，不要直接輸入 `.\xxx.ps1`。
- 找不到脚本：先做第 2 節定位；原始碼與安裝版路徑不同。
- 搜尋失敗：Docker Engine running → Start-SearXNG → 重啟 Agent → 查看搜尋狀態。
- 手機 502：檢查電腦開著、桌寵說「開啟手機配對」，確認 tunnel 指向 3221。
- 手机 401：重配對；不要使用過期的一次性碼。
- 無語音：先確認播放裝置、語音回覆開關，再測試；不要只看麥克風音量指示。
- 模型未下載：重跑首次 Setup。Idle CPU-only，不應常駐 GPU 主模型。
- 一般泡泡 15 分鐘收起；開啟歷史模式可保留。重開不自動播放上次話語。
- 安裝版記憶 `%LOCALAPPDATA%\DailyAgent\data`，模型／寵物設定在 `runtime`；備份前先正常關閉程式。
- 本版未完成 Android 真機完整驗收；固定 Cloudflare tunnel 需由帳號持有人完成配置。

## 9. 原始碼建置（開發者）

從 GitHub clone 本專案後，在專案根目錄開 PowerShell。先安裝 Node.js 24+（https://nodejs.org/），C# 編譯另需 Windows SDK（https://developer.microsoft.com/windows/downloads/windows-sdk/）。套件管理器若被 PowerShell 限制可用 npm.cmd：

```powershell
Set-Location .\daily-agent
npm.cmd ci
node --test tests/*.test.js
Set-Location ..
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-DailyAgent.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-DailyAgent.ps1
```

Android 工具只供編譯／ADB，不是手機使用者必需：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\android\Setup-AndroidTools.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\android\Test-Android.ps1 -Build
```

首次 Android 建置會在自己的 `.daily-runtime` 產生簽章金鑰。請自行備份，勿上傳 Git；更換金鑰無法覆蓋原簽章 APK。官方 Release APK 的簽章金鑰不隨原始碼發布。

原生桌寵檢查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\desktop\Build-Pet.ps1 -SelfTest
```

Windows 通知身分選用安裝（先關閉桌寵；會信任本機產生的 CurrentUser 憑證並註冊身分）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\daily-agent\desktop\notification-package\Enable-Identity.ps1
```

詳見同目錄 README 的撤銷方式；不要刪除其他程式的憑證。
