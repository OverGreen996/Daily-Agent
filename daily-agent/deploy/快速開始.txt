Daily Agent 快速開始

1. 只下載 DailyAgent-Setup.exe，雙擊後按「安裝並開始使用」。
2. 保持「安裝後自動準備基本功能」勾選。中文設定視窗會準備本地模型並開啟桌寵。
3. 桌寵點一下開啟聊天、再點收合；直接打字，不需要操作 PowerShell。
4. 平時雙擊桌面 Daily Agent。補裝或重試請開 Daily Agent 功能與設定。

第一次只用基本版：
・磁碟先預留約 12 GB（包含下載、解壓縮與模型轉換的暫時空間）。
・不用先裝 Docker、WSL、Python、Node，也不用申請 Cloudflare 或 Google 帳號。
・首次下載需要時間；設定視窗會顯示正在下載的項目及進度。
・看到「開始聊天」後即可使用。需要其他功能時再勾選。

卡住時只做這幾件事：
・下載中斷／重開機：開 Daily Agent 功能與設定 → 繼續下載／修復。
・磁碟空間不足：安裝器 → 變更安裝位置；補裝前先看預估空間。
・想用語音／生圖：補裝功能 → 勾選需要的項目 → 下載並配置。
・生圖提示不支援顯示卡：先用基本版；本地生圖需 NVIDIA 及至少 8 GB 顯存。
・看不到桌寵：開 Daily Agent 功能與設定 → 開始聊天。
不用刪模型、重裝電腦或複製技術指令。進階排錯再查看配置紀錄。

功能與設定有四個區塊：
開始使用：啟動聊天、檢查必要模型、查看配置進度。
補裝功能：勾選語音、生圖或外網連線，再下載。
模組管理器：設定搜尋 API、啟用／停用各功能；儲存後完整關閉並重開生效，資料保留。
連線與維護：手機／PocketDrop 配對、記憶宮殿、清理安裝暫存、卸載。

可直接說：
記住：我喜歡簡短回答
明天下午三點提醒我開會
我明天要做什麼？
查看待辦
幫我查今天的新聞
幫我傳到手機：這段文字（需先配對 PocketDrop）

基本聊天、記憶與行程不需要生圖、Docker、Cloudflare 或網域。
本地模型第一次需要下載；空間依勾選功能而定，不會一開始下載所有生圖模型。
手機需要電腦開著；外網連線請用自己的 Cloudflare 帳號與設定。
完整卸載請到 Windows「已安裝的應用程式」，或功能與設定的卸載入口。
卸載可選保留記憶宮殿；模型不列在保留範圍。
