更新很簡單

開啟 XNG 管理器 →「檢查更新」→確認版本→安裝→重新啟動。通過校驗及回歸才切換；失敗保留舊版，也能回復上一版。

將這個網址設為更新来源：

/xng-update.json

套件有 SHA256。核心版本與本機快取分開，更新不會清除個人記憶或模型。

只分享優化規則，搜尋留在自己的電腦

每位使用者自行架設 XNG。Cloudflare 只提供公開核心、工具與來源規則下載，不提供 Kent 的搜尋服務。私人設定、搜尋紀錄、快取與憑證不會放入下載包。

先更新插件管理工具，再選「來源規則」→檢查更新→確認安裝→重新啟動 XNG。個人覆寫優先，所有本機 App 共用生效。本版來源規則沿用已驗收的分類與權重，並未宣稱新增搜尋準確率。
