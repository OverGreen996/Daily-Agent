更新很簡單

開啟 XNG 管理器 →「檢查更新」→確認版本→安裝→重新啟動。通過校驗及回歸才切換；失敗保留舊版，也能回復上一版。

將這個網址設為更新来源：

/xng-update.json

套件有 SHA256。核心版本與本機快取分開，更新不會清除個人記憶或模型。

任何程式都能接入

已有獨立 XNG：同一台電腦直接使用 HTTP API。沒有 XNG：先準備獨立 Node、Docker 與 SearXNG，再依教學安裝。此下載站不提供雲端搜尋端點。

GET  http://127.0.0.1:8889/health
POST http://127.0.0.1:8889/ai/search
{"query":"Firefox 最新正式版本","mode":"normal","limit":3}

回傳來源、日期、引用段落與限制；由你的 App 生成答案。普通 /search?q=...&format=json 保持相容。
