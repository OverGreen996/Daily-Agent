# Android 預覽版 8

- 內建寵物圖集改用原始解析度，不再先縮成一半後放大。原圖本身的細節仍是畫質上限。
- 背景只顯示寵物，不主動彈出對話泡泡；點寵物展開聊天，再點收合。
- 打開聊天不自動彈鍵盤，點輸入框才開始輸入。
- 設定新增 40%～200% 大小拉條、外觀預覽與恢復預設大小。最小約為一個 App 圖示，尺寸會保存。
- 設定、文字指令和通知列的關閉入口統一停止服務、移除懸浮窗並關閉 App 畫面，關閉期間不重建懸浮窗。

驗證：三組 JVM 規則測試、APK 編譯與 v2/v3 簽章驗證通過。未連接 Android 實機，觸控、輸入法與系統懸浮窗仍需實機驗收。

直接覆蓋安裝同簽章的旧版 APK，不需先解除配對。
