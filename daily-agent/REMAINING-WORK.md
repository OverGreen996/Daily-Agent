# 後續維護與驗收

目前版本為 0.2.2 預覽版，功能與限制以 [現版本介紹](docs/現版本介紹.md)、[驗證紀錄](VALIDATION.md) 為準。這份清單列出仍需要的工作，舊版「搜尋／生圖未做」不再代表目前狀態。

| 優先項目 | 完成條件 |
| --- | --- |
| Android 實機驗收 | 安裝、配對、點擊收合、縮放拉條、圖片、權限、切網、背景與耗電實测 |
| Google Drive 真實驗收 | 用自己的 OAuth 用戶端完成登入、備份、下載校驗、到期重新登入及撤銷 |
|  | 配對、自然語句傳送、重啟後再次傳送，核對手機收到的內容 |
| Windows 通知 | 使用者允許身分與通知權限後，驗證真實接收及去重 |
| 安裝器正式簽章 | 決定發行者憑證與簽署流程，保持 hash／OTA 校驗 |
| 更廣硬體驗收 | 不同 Windows／GPU／音訊設備配置，記錄下載大小、速度與失敗復原 |
| 手機更新介面 | 消費既有 `/v1/updates`，顯示版本、校驗及 Android 使用者安裝確認 |

維護時先保留使用者資料，功能停用與程式移除分開處理；新增接口走模組宿主。搜尋透過 Daily 自己的三家 API 適配器；調整供應商或輪替策略時跑隔離接口測試，不再同步外部搜尋核心。
