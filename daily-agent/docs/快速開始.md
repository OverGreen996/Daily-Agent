# 第一次使用 Daily Agent

[← 回首頁](../../README.md) · [完整安裝與排錯](../deploy/使用教學.md) · [對話指令](../deploy/對話指令.md)

先把電腦聊天用起來，再補需要的功能。Windows 公開版為 0.2.2 release 12，手機為 Preview 10；XNG 等獨立工具另行更新。

## 1. 電腦：下載一個檔案

1. [下載 DailyAgent-Setup.exe](https://github.com/OverGreen996/Daily-Agent/releases/latest/download/DailyAgent-Setup.exe)。
2. 雙擊，按「安裝並開始使用」。
3. 保持「安裝後自動準備基本功能」勾選，等待模型下載與配置完成。
4. 桌寵出現後點一下打開聊天；再點一下收合。

Windows x64；本輪實測硬體為 RTX 3080 Ti 12 GB，其他配置不等於已驗收。首次準備需要網路與約 12 GB 暫時空間，以畫面檢查為準。基本功能不需要先裝 Docker 或申請 Cloudflare。

**不需要另抓 ZIP／sha256，也不用另外安裝 Node 或先輸入 PowerShell。** 若下載中斷，開桌面「Daily Agent 功能與設定」→「繼續下載／修復」。

## 2. 試一次記憶與行程

分別傳送這些訊息：

```text
記住我叫小明，我是設計師
我明天下午三點要開會
我明天要幹嘛
```

核對回覆中的日期與時間，確認後再使用提醒。資料保存在這台電腦的宮殿；刪除個人記事不等於刪除歷史聊天。提醒需要電腦後端運行，電腦關機時不能準時通知。

## 3. 需要什麼，再補什麼

| 想做的事 | 下一步 |
| --- | --- |
| 語音朗讀／中文語音輸入 | 「補裝功能」勾選對應資源，再選播放裝置／麥克風 |
| 生圖 | 勾選動漫或真人模式；兩種分開下載，檢查 NVIDIA 驅動與顯存 |
| 看文件、做摘要 | 拖入支援文件；掃描文件另需 Windows OCR 語言 |
| 即時搜尋 | 配置搜尋模組；已有 XNG 可按[接入教學](../deploy/XNG接入教學.md)沿用 |
| 用手機聊天 | 按下面的手機順序操作 |
| 傳文字到自己的手機 | 先完成 [PocketDrop 配對](../deploy/PocketDrop接入教學.md) |
| 更換外觀 | 右鍵設定匯入素材；整張動畫圖用[外觀編輯器](../deploy/動畫圖匯入教學.md) |
| 備份記憶 | 看 [Google Drive 設定](../deploy/GoogleDrive備份教學.md)，先準備自己的 OAuth 用戶端 |

「補裝功能」決定這次下載的資源；「模組管理器」決定下次啟動載入的功能。停用不刪資料或模型；儲存後完整關閉背景服務再開。

## 4. 手機：先裝 APK，再配對電腦

1. 掃電腦安裝器／設定頁的 QR Code，或[直接下載 APK](https://github.com/OverGreen996/Daily-Agent/releases/download/android-preview-10/DailyPet-Android.apk)。
2. Android 8 以上，依系統提示允許本次安裝。Preview 9 以前先移除舊版再裝，手機舊設定會清除；PC 記憶保留。
3. 電腦配置手機連線，取得自己的連線網址。外網先看[Cloudflare 教學](../deploy/使用教學.md#5-手機配對與-cloudflare)；Quick Tunnel 可先測試，固定網址使用自己的網域。
4. 電腦說「開啟手機配對」，手機填自己的連線網址與 5 分鐘有效的 8 位碼。
5. 依需要授權懸浮窗、通知與定位。

輕點寵物開／收聊天，長按開設定；「寵物大小」拉條可調 40%～200%，不必使用雙指。拖曳可移動，設定的關閉功能可停止懸浮與連線服務。

手機不下載模型。聊天、看圖與生圖都由開著的電腦處理；APK 下載本身不依賴電腦開機。配對桌寵與加入 PocketDrop Room 是兩個獨立流程。

## 5. 日常啟動、關閉與更新

| 操作 | 入口 |
| --- | --- |
| 開桌寵 | 桌面「Daily Agent」 |
| 補裝／修復／模組管理 | 桌面「Daily Agent 功能與設定」 |
| 完整停止 | 桌寵右鍵 → 關閉桌寵並停止背景服務 |
| Windows 更新 | 以下更新指令；自訂目錄請換成自己的路徑 |
| 卸載 | Windows 已安裝的應用程式 → Daily Agent；可選保留記憶宮殿 |

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DailyAgent\Update-DailyAgent.ps1" -Install
```

更新完成後重開桌寵。模型、記憶與設定保留；回復程式不代表資料庫已備份。手機 APK 由 GitHub 獨立發布，安裝仍需 Android 系統確認。
