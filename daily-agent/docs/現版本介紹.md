## 這次主要改變

- 搜尋使用自己的 Exa／Tavily／Firecrawl API，支援順位、額度上限、冷卻、快取與備援；金鑰用 Windows DPAPI 保存。
- Qwen 先理解聊天與搜尋需求；生圖、文件與明確助理命令維持各自處理路徑。
- Daily 的模型服務、搜尋資料與後端各自獨立；可選模組缺失或模型離線時，設定與本機記憶仍可使用。
- 修正 PET 匯入工具尋找安裝位置，以及卸載器識別實際安裝路徑；使用者外觀與模型放在發行目錄外。
- 安裝改成單一 EXE，內附程式與校驗資料，解決缺少 ZIP／sha256 的舊流程。基本功能自動配置，額外功能勾選後才下載。
- 中文深色設定視窗集中管理開始使用、補裝、模組、連線與維護，支援下載續傳、修復、資源重用及清理暫存。
- 功能拆成 10 個模組，各有入口、工具、API、相依與停止清理。第三方本機插件可走相同接口，核心不需要增加專用分支。
- 程式碼、模型、個人資料分開存放；更新與回復程式版本不搬動模型，卸載可選保留宮殿。
- 寵物外觀編輯器可直接匯入整張動畫圖，自動切格、去除邊緣背景、對齊腳底、檢查跳動與品質，支援手動微調及匯出。
- APK 獨立放 GitHub，Windows 安裝器與設定頁提供 QR Code。手機支援收合泡泡、縮放拉條、圖片顯示及配對恢復。
- Google Drive 備份模組提供登入、快照、下載校驗與選用每日備份；本次沒有內附公用 OAuth 用戶端。

## 功能與需要下載的東西

| 類別 | 內容 | 是否必要 |
| --- | --- | --- |
| 基本版 | portable Ollama、Qwen3.5 4B、CPU 待機小模型、embeddinggemma、tokenizer | 第一次自動配置 |
| 語音朗讀 | Kokoro 模型與語音資源 | 選配 |
| 中文語音輸入 | Zipformer／Sherpa 語音辨識模型 | 選配 |
| 瀏覽器 | 自動化瀏覽器資源 | 選配 |
| 動漫／真人生圖 | ComfyUI、所選 checkpoint 與放大資源 | 選配，兩種模式分開勾選 |
| 外網手機連線 | cloudflared 與自己的 Cloudflare 設定 | 選配 |
| 手機 | 約 2.7 MB 的 APK；不下載模型 | 選配 |
| Drive 備份 | 自己申請的 Google Desktop OAuth 用戶端 | 選配；尚未做真實帳號驗收 |

安裝包含 Node 執行環境；ComfyUI 的選配包含自己的 Python。一般使用者不用安裝 Android SDK、JDK 或開發用編譯器。模型與依賴會按所選功能另行下載，網速和空間會影響首次配置時間。

基本版首次預留約 12 GB（含暫存）。每個生圖 checkpoint 約 7 GB，ComfyUI 與下載解壓另計；不要把全選功能的空間當成基本版需求。以設定視窗當下的估算及磁碟檢查為準。

## 日常操作

點桌寵開／收聊天；手機長按寵物開設定，在設定中拉動縮放條調整大小，可以縮到接近 App 圖示。一般訊息 15 分鐘後收起，歷史模式例外；重新開啟不重播上一則回答。

| 你可以說 | 用途 |
| --- | --- |
| 記住我叫小明，我是設計師 | 個人資料記憶 |
| 我明天下午三點要開會 | 新增行程；日期以使用者時區解讀 |
| 我明天要幹嘛 | 查詢行程 |
| 幫我搜尋最新 AI 新聞，附上來源 | 使用搜尋模組核對來源與日期 |
| 開啟手機配對 | 取得限時配對碼 |
| 模組管理器 | 開功能管理 |

更多精確指令與生圖模式操作見 [對話指令](../deploy/對話指令.md)。生圖提示詞不進宮殿；生成圖片仍保存在本機圖片目錄，使用者可以自行清理。

## 更新相容性

Windows 更新保留宮殿、設定、模組選擇與共享模型。回復只切換程式版本，不能代替資料庫備份。

Android Preview 10 更換固定新簽章。Preview 9 以前需移除舊版、重新安裝與配對，舊手機設定不會保留；電腦記憶宮殿不受影響。Preview 10 之後使用同一簽章，支援覆蓋更新。手機 OTA 目前提供接口，沒有自動更新畫面。

搜尋預設依 Exa → Tavily → Firecrawl 的順位使用第一個可用服務。未設定金鑰時提示「搜尋尚未設定」；一般聊天、記憶、行程與生圖仍可使用。正式帳戶的額度及搜尋品質仍待個別驗證。
