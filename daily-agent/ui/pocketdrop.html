PocketDrop 連線設定

請在 Room 主機的 PocketDrop 按「邀請裝置」，截取 QR Code 並選取圖片。QR 只在這台電腦解碼；一次性邀請不會送進聊天或記憶宮殿。

電腦必須與 PocketDrop Room 在同一個區域網路。這個頁面不會把 PocketDrop 開放到網際網路。
