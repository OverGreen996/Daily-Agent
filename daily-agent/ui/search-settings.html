進階設定

聊天每回合最多兩次查詢。每次查詢每家最多嘗試一次，排隊也計入時限。429 優先使用供應商的 Retry-After。

用量怎麼算？

預設本機上限：Exa 9 美元、Tavily 900 credits、Firecrawl 900 credits。數字是保守用量紀錄，失敗請求也會保留，不等於供應商帳戶的實際餘額。

Tavily 與 Firecrawl 會核對官方餘額；Exa 一般金鑰沒有餘額接口。請在三家後台選免費方案、關閉自動加值或付費，並避免與其他服務共用金鑰。本機限制無法控制帳戶外部的花費。

金鑰使用目前 Windows 帳號加密保存。這些設定只用於 Daily Agent，與靈動島分開。手機不會取得金鑰；Cloudflare 不需修改。
